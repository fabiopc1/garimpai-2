PARA PUBLICAR VIA GITHUB + NETLIFY
1. Faça backup do estado atual do repositório.
2. Extraia o ZIP; copie TODOS os arquivos na raiz do repositório, preservando as pastas site/ e netlify/.
3. Faça commit. Se o repositório estiver conectado ao Netlify, o deploy ocorrerá de acordo com as configurações do projeto.
4. No Netlify, Build settings: publish directory = site, functions directory = netlify/functions (já definidas em netlify.toml).
5. Teste o endereço e /api/produtos. Não insira chaves de API no navegador ou no GitHub.
